# CaesarAICareerOps — FastAPI Web Co-Pilot & Dashboard

A clean, stable, lightweight **FastAPI Web Co-Pilot** built specifically for `career-ops`. It runs locally alongside `career-ops` to provide a visual interface and REST API layer.

---

## 🌟 Key Features

1. **📊 Interactive Applications Tracker:**
   - Table and status dashboard for tracking all your applied roles from `data/applications.md`.
   - Update application statuses with a single click (`Evaluated`, `Applied`, `Interview`, `Offer`, `Rejected`, `SKIP`, `Hired`).
   - Filter and search applications by company or job title.

2. **⚡ Real-Time Job Evaluator:**
   - Paste job descriptions or URLs directly into the browser.
   - Executes 7-Block evaluation (`gemini-eval.mjs`) and outputs score breakdowns.

3. **🔍 ATS Portal Scanner Control:**
   - Run portal discovery scans (`scan.mjs`) across Greenhouse, Lever, Ashby, etc.
   - Run with Playwright liveness verification (`--verify`).

4. **📄 Evaluation Reports & ATS PDF Generator:**
   - View formatted Markdown evaluation reports in `reports/`.
   - Trigger ATS-formatted PDF resume generation (`generate-pdf.mjs`) and download result PDFs from `output/`.

5. **📝 Master CV & Profile Editor:**
   - View and edit `cv.md` and `config/profile.yml` directly from your browser.

6. **🛠️ Interactive Swagger REST API Docs:**
   - Interactive OpenAPI documentation auto-generated by FastAPI at `http://127.0.0.1:8000/docs`.

---

## 🚀 How to Run

### 1. Launch the Server

From the `CaesarAICareerOps` root directory, run:

```bash
python3 run_server.py
```

Or run via Uvicorn directly:

```bash
uvicorn main:app --reload --host 127.0.0.1 --port 8000
```

### 2. Access the Dashboard

- **Web Dashboard:** [http://127.0.0.1:8000](http://127.0.0.1:8000)
- **Interactive API Docs (Swagger):** [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)
